# hh_ext_filesize
hh_ext_filesize is a TYPO3 extension.
It adds a backend module to list all files within a directory (custom) which are greater then a given size (kilobytes).
You can sort it currently by "path" and "size".

### Installation
... like any other TYPO3 extension [extensions.typo3.org](https://extensions.typo3.org/ "TYPO3 Extension Repository")
Don't forget to include PageTS / look at features section
